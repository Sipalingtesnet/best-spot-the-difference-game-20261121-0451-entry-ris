# Twin Lanterns — Spot the Difference

Twin Lanterns is an original spot-the-difference game for the make.fun bounty
[best-spot-the-difference-game-20261121-0451](https://make.fun/bounty/best-spot-the-difference-game-20261121-0451).
Three hand-drawn scenes — a night-market lantern stall, a lighthouse at dawn, and a
garden tea party — are painted entirely by the game itself with canvas shapes and
gradients, with no downloaded images, no external files and no network requests. Each
round shows two near-identical pictures side by side with exactly seven differences
hidden between them. Find all seven in each round to advance, and finish all three
rounds to see your results with a score, total time, accuracy and one to three stars.

## How to play

Play with the mouse or the keyboard. Click a difference on either picture with the
mouse to mark it; a found difference gets a red circle drawn on both pictures. Or move
the crosshair with the arrow keys and press Enter or Space to mark the spot under it.
A wrong click shakes the picture briefly, plays a low buzz and costs 5 seconds. The
top bar always shows how many differences are found out of 7 and how many remain, plus
a 180-second round timer and your score. Press H (or the Hint button) to circle one
unfound difference faintly for a few seconds at a cost of 50 points. R restarts the
current round, N moves to the next round after a round is complete, and M mutes and
unmutes the sound, which is made with the browser's built-in audio synthesis only, no
audio files.

## Run it locally

Serve the game folder with the included static server, then open the address it prints:

```
node serve.ts
```

The server listens on localhost only, at http://127.0.0.1:8080, and serves the game
folder with the right content types, refusing any path outside it. Open that address in
a desktop browser to play.
